VARIABLES

# variable in javaScript is used to store data values. 
In JavaScript, we use the keywords var, let, or const to declare variables.

1. Variable names are case sensitive 'a' & 'A' is different.
2. Only letters, digits, underscore ( _ ) and $ is allowed. not even space.
3. Only letter, underscore or $ should be 1st character.
4. Reserved words cann't be variable names. 


let, const & var

var : Variable can be re-declared & updated. A global scope variable.
example:-
            var fName = "Pawan";
            var fNmae = "Shravan";              => this is possible with var keywords
                fName = "ashruba";              => this is possible with var keywords, it will update the value

let : Variable cannot be re-declared but can be updated. A block scope variable.
example:-
            let fName = "Pawan";
            let fName = "Shravan";              => this is not possible with let keywords
                fname = "ashruba";              => this will update the previous value of fname and this is possible
            let a;                              => this will declare the variable and after that we can use it globally and update the values.
            a = 10;

const : Variable cannot be re-declared or updated. A block scope variable.
example:-
            const pay = 3.14;
            const pay;                  => not possible with const
            const pay = 9.8;            => this is not possible with const keywords
                  pay = 10;             => this is not possible with const keywords

CONDITIONAL STATEMENTS

1. if Statement
Example:-

let color;
if(mode === "dark-mode"){
    color = "black";
}

2. if-else Statement
Example:-

let color;
if(mode === "dark-mode"){
    color = "black";
}else{
    color = "white";
}

3. else-if Statement
Example:-

if(age > 18){
    console.log("Junior");
}else if(age > 60){
    console.log("Senior");
}else{
    console.log("Minor");
}

4. The ternary operator:  is a shorthand for the if-else statement and is often used for simple conditional assignments.
Example:-

let age = 2;
let canVote = (age >= 18) ? "Yes, can vote" : "No, cannot vote";
console.log(canVote);

5. Switch statement: if you have multiple conditions based on the same variable, a switch statement can be more readable than multiple if-else statements.
Example:-

let fruit = "Apple";
switch(fruit){
   case "Mango":
       console.log("King of fruits");
         break;
    case "Apple":
         console.log("Red fruit");
            break;
    case "Banana":
            console.log("Yellow fruit");    
            break;
    default:
        console.log("Unknown fruit");
}

LOOPS IN JAVASCRIPT
Loops in JS are used to execute a piece of code again & again

1. for Loop
Example:- 

for(let i = 1; i <= 5; i++ ){
    console.log("for loop");
}

2. while Loop
Example:-

let a = 10;

while(a <= 10){
    console.log(a);
    a++;
}


3. do-while Loop
Example:-

let b = 5;
do{
    console.log(b);
    b++;
}while(b <= 10);


4. for-of Loop in JavaScript
// It used for string and arrays

let std = "Rakesh Roshan";

for(let val of std){
    console.log("Value:", val);
}


5. for-in Loop

let obj ={
    drink : "cock",
    test : "Not-good",
    isHealdhy : false
}

for(let key in obj){
    console.log(key, obj[key])
}
